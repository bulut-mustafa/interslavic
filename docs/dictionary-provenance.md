# Dictionary provenance and licensing posture

## Source

The Interslavic wordlist is a **public Google Sheet** read as TSV, with no authentication:

```
https://docs.google.com/spreadsheets/d/1N79e_yVHDo-d026HljueuKJlAAdeELAiPzdFzdBuKbY/export?format=tsv&gid=1987833874
```

Verified 2026-10-17: HTTP 200, 7.9 MB, **19,100 data rows**, 26 columns.

It backs [interslavic-dictionary.com](https://interslavic-dictionary.com/), whose app code
([sonic16x/interslavic](https://github.com/sonic16x/interslavic)) is MIT.

## Licensing: why the snapshot is not committed

The app code is MIT, but **the wordlist is a different artifact from the code**:

- it originates in Jan van Steenbergen's work at `steen.free.fr`, whose published material
  is **CC BY-NC-ND 3.0**;
- the repository states **no explicit license for the data itself**;
- the maintainers describe the project only informally as "a non-profit open source
  project... we don't make money from it".

So: personal, non-commercial use with attribution is almost certainly fine. Redistribution
or any commercial use is legally ambiguous and would need the maintainers' permission first.

**Posture adopted here**

1. The TSV is **gitignored**, never committed.
2. `packages/lexicon/data/provenance.json` records the source URL, SHA-256, byte count,
   row count and fetch date — reproducibility without redistribution.
3. Attribution appears in the README.
4. Access goes through the `Lexicon` reader, so the data source stays swappable.

Re-fetch deliberately with `npm run lexicon:fetch`, which also **fails loudly on schema
drift** rather than silently mis-parsing a renamed column.

## Column semantics worth knowing

Established by probing the live sheet; several contradict what the surrounding
documentation implies.

| Column | Notes |
|---|---|
| `isv` | Headword, in the **etymological** alphabet (`hlåpėc`, not `hlapec`). Leading `!` = autogenerated (6 rows), `#` = flagged (79 rows). Commas appear in only 245 rows; **1,917 rows (10%) are multiword**. |
| `addition` | Irregular forms, **and numeric government codes**: `(+2)`=Gen `(+3)`=Dat `(+4)`=Acc `(+5)`=Ins `(+6)`=Loc. There are **zero** `(+gen)`-style named codes. Verb principal parts are grouped by semicolon. |
| `partOfSpeech` | e.g. `m.anim.`, `f.`, `v.tr. ipf.`, `num.card.`. Biaspectual verbs carry both aspect markers and should get **no** aspect feature. |
| `type` | Flavor rank 1-9, but **14,163 of 19,100 are rank 1** and 799 are empty, so it is far too coarse to rank with on its own. |
| `frequency` | 0-11,399, higher = commoner. **This is the real tie-breaker.** |
| `en` | Comma-separated glosses; **837 rows** carry a parenthesised sense label (`affair (adultery)`). Ambiguity is severe: `order` has 22 candidates, `connect` 19. |
| aspect pairs | **There is no aspect-pair column.** Grouping verbs by identical `en` gloss recovers **1,616 ipf/pf pairs** automatically (905 glosses are ipf-only). |
