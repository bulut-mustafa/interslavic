# Studio: learn Interslavic while posting about it (proposed)

Status: proposed design, not built.

## Context

Many people learning Interslavic share their progress - posts, captions, short videos -
and dictionaries make them look up every word by hand. Studio is a phone-first page that
turns one sentence into something learned and something shareable:

**write a sentence -> understand the Interslavic -> save it -> export a caption or an
image card.**

Interface language: English first, with every interface text kept in one module so other
interface languages can follow.

## The flow (one new tab: Studio, at `/studio`)

1. **Write.** One box, "Write in Russian or English". The language is detected (any Cyrillic
   letter -> Russian, otherwise English), so there is no switch. A Translate button.
2. **Understand.** The Interslavic in large type, Latin with Cyrillic beneath. Every word is a
   tappable chip; tapping opens a bottom sheet:
   - **Meaning**: the dictionary's English gloss and its Russian word(s).
   - **Like Russian**: "Same as Russian" / "Close to Russian: приятель" / "Different - Russian
     says друг" (rules below).
   - **Why this form**: the first line of the translator's existing explanation for the word.
   - **How sure**: a word the translator guessed is marked, with "check this before posting".
3. **Save.** A ★ on the sentence and on each word saves it to the Notebook.
4. **Export.**
   - **Copy caption**: Interslavic (Latin), then Cyrillic, then the original sentence.
   - **Sentence card** (image).
   - **"Every Slav" card** (image) for a chosen word.
   Both cards in square 1080x1080 (posts) and tall 1080x1920 (Reels covers). On the phone the
   share sheet opens with the image (one tap to save or post); elsewhere it downloads.
5. **Notebook** (`/studio/notebook`). Everything saved, newest first; re-open to export again;
   review saved words as flashcards (the phrasebook's card component).

## Rules that decide what is shown

**"Like Russian" - by spelling, fixed rules, never guessed.**
1. The entry's Russian words: `Entry.ruGlosses` (dictionary `ru` column).
2. The Interslavic lemma written in Cyrillic (`toCyrillic`), then normalised to Russian
   spelling by an ordered table (ја->я, ју->ю, љ->ль, њ->нь, ј->й after a vowel, ы for y,
   е for ě, ...). The table lives in one file with a test per row.
3. Compare: identical -> "Same as Russian"; Levenshtein distance <= 2 and <= 25% of the
   length -> "Close to Russian" (shows the Russian word); otherwise "Different" (shows it).
It speaks about form only; the meaning is shown separately. No "false friend" claims.

**Accuracy before posting.** If any word's decision was a `guess`, Export first shows "N words
are guesses - check them" and highlights them; exporting stays possible. Every card carries
`interslavic.web.app`; the "Every Slav" card also "Words: interslavic-dictionary.com".

**"Every Slav" card data.** For the chosen lemma: its word in ru, uk, be, pl, cs, sk, sl, hr,
sr, mk, bg (dictionary columns), and each language's mark from the dictionary's
`intelligibility` column: ✓ understood (+), ~ partly (~), ✗ not (-); a language the column
does not list shows no mark ("no data"), never ✗. A cell starting with `!` (very common:
12,043 cells in ru/pl/cs/sl alone) is undocumented; in the headword column `!` means
"autogenerated", so such a word is shown in a lighter style as unconfirmed. Nothing on the
card is computed by us except layout.

## Components

| Unit | Does | Depends on |
|---|---|---|
| `packages/lexicon/src/reader.ts` | `Entry` gains `cognates: Record<lang, { word: string; confirmed: boolean }>` and `intelligibility: Partial<Record<lang, '+'\|'~'\|'-'>>` | the TSV columns |
| `packages/server/src/main.ts` | `GET /api/entry?lemma=&pos=` -> gloss, Russian, cognates, intelligibility. Dictionary data stays server-side, never in the static site | Lexicon |
| `web/src/studio/detect.ts` | Russian or English from the text | - |
| `web/src/studio/like-russian.ts` | the spelling rules above; pure | `toCyrillic` |
| `web/src/studio/notebook.ts` | saved items in localStorage, try/catch like `learn/progress.ts` | - |
| `web/src/studio/cards.ts` | lays out a card (pure: lines, sizes, positions) and draws it on a canvas | Plex fonts (`document.fonts.load` first) |
| `web/src/studio/share.ts` | `navigator.share({ files })` when `canShare`, else a download | - |
| `web/src/studio/text.ts` | every interface string (for the later Russian interface) | - |
| `web/src/pages/Studio.tsx`, `Notebook.tsx` | the screens; reuse `/api/translate` and the existing word data (`GlossedWord`) | the above |

Routing, prerendering, sitemap and page metadata extend the existing `router.tsx`,
`meta.ts` and `entry-server.tsx` (Studio gets its own title/description; Notebook is
`noindex` - it is personal).

## Card look (defaults; to review on the phone)

Site palette and fonts. IBM Plex Serif for Interslavic, Plex Sans for everything else; light
background, dark ink, the site's teal for accents; generous margins sized for phone feeds.
Sentence card: Interslavic (Latin) large, Cyrillic below it, the original sentence small,
footer URL. "Every Slav" card: the word large with its English meaning, then a two-column
list of the 11 languages - language name, its word, its ✓/~/✗ - and the footer credits.

## Errors

- Translator API asleep or down: the existing "warming up" behaviour; Studio says so.
- `/api/entry` fails: the sheet shows meaning and form from the translation, hides "Like
  Russian" and disables the "Every Slav" card for that word, with a short reason.
- Storage unavailable (private mode): saving is disabled with a one-line reason.
- `navigator.share` refused or missing: fall back to download.

## Testing

- Unit: `like-russian` (a fixed list including voda/вода same, prijatelj/приятель close,
  prijatelj/друг different, dobry/добрый, govoriti/говорить), `detect`, `notebook`
  (round-trip, storage throwing), card layout (long sentences wrap, nothing leaves the frame,
  both sizes), reader `cognates`/`intelligibility` on known rows, `/api/entry` responses.
- UI (testing-library, mocked fetch): write -> translate -> tap word -> sheet shows Russian and
  label -> save -> appears in Notebook -> export warns on guesses.
- SEO tests extended: Studio has its own head; Notebook is `noindex` and not in the sitemap.
- Manual: Chrome at phone width (375-414px) - the whole flow one-handed, and a real share to
  the camera roll on a phone.

## Out of scope (this version)

Subtitles (.srt), read-aloud / stress guide, the Russian interface, sync between devices,
accounts, whole-sentence comparisons across Slavic languages (the dictionary is word by word;
the translator only goes into Interslavic).

## Open question

The dictionary's terms are non-commercial. Cards built from its comparison data, posted by a
monetised account, are a grey area - worth asking the dictionary maintainers.
